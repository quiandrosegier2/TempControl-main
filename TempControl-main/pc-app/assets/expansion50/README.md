# Expansion 51–100 original artwork

47 original illustrations were generated with the built-in image_gen tool through the imagegen skill. Final PNGs are production-resized to 412 × 412 using `installer/prepare-neon-artwork.ps1`. `provenance.json` records each final prompt and original generated filename. Project assets are embedded; the installed app does not depend on the tool's generated-images directory.

Biohazard (77) and Quantum Core (99) use native decorative graphics from `ExpansionArtwork.cs`. RGB Dream (100) uses an editable, animated `InfinityRibbon` widget on a native background. The katana glow in Neon Ronin is a separate editable `NeonLine` widget. All clocks, dates, readings and load indicators remain separate editable objects.

The 51–100 poster mentioned in the brief was not received. Artwork follows the written themes and original-character requirements. No missing illustration is represented as a completed asset. A match to an unseen poster and physical ESP32 appearance are not claimed.
